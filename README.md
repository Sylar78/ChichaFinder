# ChichaAroundMe

Application de recherche et découverte de bars à chicha.

## 🚀 Démarrage rapide

### Installation

```bash
npm install
```

### Développement

```bash
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000) dans le navigateur.

### Build production

```bash
npm run build
npm start
```

## 📁 Structure du projet

```
ChichaAroundMe/
├── components/        # Composants React réutilisables
├── pages/            # Pages Next.js et API routes
├── public/           # Assets statiques
├── styles/           # Styles globaux
├── lib/              # Bibliothèques et utilitaires
└── utils/            # Fonctions helper
```

## 🛠️ Technologies

- **Framework:** Next.js 13.4.12
- **UI:** React 18.2.0
- **Styling:** Tailwind CSS 3.2.0
- **Icons:** Lucide React
- **Maps:** Leaflet + OpenStreetMap

## 📋 Fonctionnalités principales

- ✅ Recherche de bars à chicha
- ✅ Carte interactive (OpenStreetMap)
- ✅ Collection personnelle de chichas
- ✅ Avis et notes
- ✅ Filtres avancés
- ✅ Listes personnalisées

## 🌐 API OpenStreetMap

L'application utilise l'API Overpass d'OpenStreetMap pour rechercher des bars à chicha.
Aucune clé API n'est nécessaire.
