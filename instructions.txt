🥈 2. OpenStreetMap + Overpass API (gratuit & open-source)
✅ Principe

OpenStreetMap contient beaucoup de bars chichas tagués comme :

amenity=bar

name ou description contenant chicha / shisha / hookah

🔍 Exemple de requête Overpass
node
["amenity"="bar"]
(around:3000,48.8566,2.3522)
["name"~"chicha|shisha|hookah",i];
out;

✅ Avantages

✔️ Gratuit
✔️ Open data
✔️ Pas de quota
✔️ Idéal backend

❌ Inconvénients

Données parfois incomplètes

Pas d’avis ni notes fiables

Dépend des contributeurs

👉 Parfait pour compléter Google Maps ou pour un projet 100 % open

Ou recherche par ville

🗺️ Affichage
